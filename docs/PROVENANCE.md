## Adaptation de portfolio

Version maintenue par **Younes Radouani**. Le nouveau module `maintenance/`, l’interface,
les tests et la documentation ont été développés avec assistance IA. Cette adaptation
ne constitue ni une expérience de stage ni un déploiement en entreprise.

La validation locale a exécuté le pipeline complet sur les fichiers hérités, puis **10 tests**,
dont les interactions du tableau de bord Streamlit. Les résultats ont été mesurés, sans
invention de performances. Versions, graine, paramètres et empreintes des données sont fournis.

En entretien, distinguer la base open source, les ajouts de cette version et les choix
techniques personnellement compris et maîtrisés.
